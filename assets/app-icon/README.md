# Spectra Paint app icon

`spectra_paint_logo.png` (512 px, a cyan crystal flower on a black rounded square, transparent corners)
is the source of the raster icons here: `photocraft-1024.png`, `photocraft.ico` and `hicolor/*`
(made with `installer/set-icon.py`, which resizes it to every size).

Not yet regenerated from the new logo (they still hold the previous drawing and are used only by
macOS packaging and an SVG import test): `photocraft.svg`, `photocraft-small.svg`, `photocraft.icns`.
